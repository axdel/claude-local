## Error Ownership

| Layer | Raises | Catches and Translates | Status | Superseded By |
|-|-|-|-|-|
| backend | BackendUnavailable, GenerationSilent, ReplayExhausted | httpx.HTTPStatusError, httpx.ReadTimeout and httpx.RequestError. No httpx type escapes this layer: a caller distinguishes an unreachable server from a model that merely failed the task, and needs no transport vocabulary to do it. The ReadTimeout arm is checked before RequestError, which it subclasses, because the two mean opposite things — a first-byte deadline expiring proves the request went out, so it is one task going silent, while a connect failure is the prerequisite missing and fatal to the whole run. ReplayExhausted is the offline backend's own: asked for more generations than it was scripted for, it fails loud with the ledger rather than returning an empty stream. | active |  |
| benchmark-harness | BenchmarkInterrupted when a harness fault escapes implement() mid-ladder, and ValueError for anything this layer cannot reduce: an oracle declaring no test, a context path outside the golden app, a duplicate or drifted context file, an empty result list, a result list disagreeing on model, rules card or planning lever, and a replayed request with no source for its target file or no target-file line at all. Both leave the layer uncaught — benchmarks.run guards case loading with its own _UsageError and the scoring call with nothing at all, so a malformed case or a mixed run surfaces as a traceback. The style measurement raises a third set that does NOT escape: FileNotFoundError for an absent linter, RuntimeError when it exits without a verdict, ValueError from parsing its output — all three caught at the style-count step, degrading to an absent count (D-BENCH-017). | A harness fault escaping implement() mid-ladder — exactly BackendUnavailable, SandboxUnavailable and OracleError. The driver re-raises BenchmarkInterrupted CARRYING the cases already completed, so run.py writes a partial scorecard rather than discarding a ladder's worth of finished work over its last rung; with nothing completed there is no measurement to keep and it exits 3 instead. Nothing marks the partial on the artifact — completeness is population-relative at comparison time, so a narrower run drops out of the ranking and a directory of only partials has no full run to be refused against (D-COMPARE-001). run.py routes to that same exit 3 each fault from the steps AFTER scoring, none of which reaches this layer as BenchmarkInterrupted; a refused artifact costs itself, never a case (D-BENCH-017). | active |  |
| cli | TaskRejected | The outermost boundary, where every error above becomes a process exit code. Three classes become TaskRejected and EXIT_REJECTED_TASK, all of them statements about the caller's envelope rather than about a model: ValueError and KeepOnlyViolation, caught together as the two refusals of the caller's own impl_path; the ValueError that TaskSpec and Budget construction raises on a malformed envelope field; and OSError reading the envelope file or json.JSONDecodeError parsing it. BackendUnavailable, SandboxUnavailable and OracleError are a broken host (EXIT_HARNESS_FAULT); a loop that ran maps its Status. A broken host is never reported as a model that failed. OSError writing the economy record is the one caught error that maps to NO code of its own: the write sits after the run, so a refused record directory is reported on stderr and the completed task keeps its verdict (D-CLI-006). | active |  |
| client | Nothing of its own. | backend's GenerationSilent, which becomes DerailReason.SILENT — the same verdict the DerailGuard reaches on a silence it CAN see. Two layers report one thing because the guard's clock advances on chunk arrival, so a stretch with no chunks in it is the one gap it is structurally unable to observe; the transport is the only layer positioned to notice. Whatever bytes did arrive stay metered, so a partial decode is still counted. | active |  |
| edits | KeepOnlyViolation | UnicodeEncodeError from encoding the reply's path and payload to bytes, which becomes the not-a-frame None that loop turns into a repairable unscorable-reply — a reply carrying an unencodable surrogate is refused whole, never half-applied. Nothing else. A reply naming a path outside the permitted impl path is refused at the point of application, so the containment rule has ONE enforcement site — but two recovery paths above it, and they recover from different things. loop catches the refusal the MODEL earned and turns it into a repairable attempt message, so a model that aimed an edit wrongly gets told so and tries again. cli catches the refusal the CALLER earned on its own impl_path and maps it to EXIT_REJECTED_TASK, since no repair can fix an envelope. Neither weakens containment: the write is already refused before either runs. | active |  |
| entrypoint | ValueError, KeepOnlyViolation, and — unmapped, by design — BackendUnavailable, SandboxUnavailable and OracleError | Nothing. A loop that RAN reports failure as a value: every terminal Status arrives inside an Outcome the caller reads, never as an exception. What escapes is disjoint from that — two refusals of the caller's own impl_path (a flat or non-nested shape, then a shape that resolves outside the worktree), and three harness faults propagated deliberately so a broken host fails loud instead of masquerading as a failed task. The distinction the earlier 'Raises: Nothing' was reaching for is real; it is about loop OUTCOMES, and stating it as 'nothing' contradicted the front door's own documented contract and the cli handler built for two of these. | active |  |
| model_registry | UnknownModel, ModelNotPresent, MalformedRegistry, UnservableCombination | A non-JSON --generation-params payload becomes argparse.ArgumentTypeError, so a front door reports it as a usage error rather than a harness fault. A PARAMS value that is not JSON is deliberately not an error: the token is kept as a bare string, so an unquoted low or auto survives. Weights absent from the store are ModelNotPresent, the designed refusal — this layer resolves and never fetches. | active |  |
| model_server | PortUnavailable, ServerExited, ServerNotReady, ServerModelUnknown, and model_registry's UnservableCombination for the flag pairing only this module can refuse | httpx.HTTPError on both probes that speak HTTP — the readiness poll and the served-models read — each becoming ServerNotReady naming the address probed, so no httpx type escapes this layer and a caller needs no transport vocabulary to tell an unreachable server from one serving nothing. A served-models answer that is not one — invalid JSON, a non-list, a missing data key — becomes ServerModelUnknown naming the address probed and quoting what arrived, because a bare KeyError teaches an operator that a dict lacked a key rather than that a proxy holds their port. ServerModelUnknown and ServerNotReady subclass LookupError and TimeoutError, so a caller reaching for the stdlib family still catches them. ProcessLookupError is suppressed during teardown, the benign race where the child is already gone. | active |  |
| model_session | Nothing of its own. | Nothing. The interactive front door deliberately lets model_registry's and model_server's named types reach the caller unchanged. An interactive caller has no value-typed failure channel the way implement()'s Outcome does, so the traceback IS the interface — which is why each of those messages names the port, the endpoint or the store path rather than assuming something above will catch and re-describe it. | active |  |
| paths | KeepOnlyViolation, ValueError | Every error strict resolution can raise — OSError, RuntimeError and ValueError, the set _RESOLUTION_ERRORS names for a malformed path, a symlink loop or a missing component — becomes KeepOnlyViolation naming the unresolvable candidate: a path the filesystem cannot resolve is refused, never trusted. This layer is the containment rule itself and fails closed: empty, absolute, symlinked-final-component, and resolving-outside-the-root are all one refusal type. The ValueError this layer RAISES is a different one that reaches no resolution: require_nested_relative_file rejects a caller's malformed impl_path by SHAPE first, which is why cli catches the two together. | active |  |
| runner | OracleError | SandboxKilled and a missing or unparseable JUnit report become OracleError. It marks the immutable test as broken, which is a distinct answer from the test being red. | active |  |
| sandbox | SandboxUnavailable, SandboxKilled | subprocess.TimeoutExpired becomes SandboxKilled, naming the oracle deadline rather than the spawn mechanism. A host that cannot confine at all raises SandboxUnavailable, which is a broken host and never a model failure. | active |  |
| sse | Nothing of its own. | json.JSONDecodeError from untrusted wire bytes, which becomes a typed Error EVENT rather than an exception: a malformed frame is one bad frame in a stream, not a broken run, so the stream stays iterable and the caller decides. Two sibling refusals take the same shape without any exception to catch — a frame past the byte ceiling and a frame that parses but is not an object. Error is a dataclass, never raised, so no wire-parsing type escapes this layer and client handles the event as data. | active |  |
| types | ValueError | Nothing — these value objects are the innermost layer and have nothing beneath them to translate. Budget, ContextFile and TaskSpec validate in __post_init__ and refuse a malformed envelope by raising ValueError, so construction is where a bad budget or spec dies and no layer above re-checks one. cli catches that class together with paths' narrower bare ValueError, both being statements about the caller rather than about a model. | active |  |

|-|-|-|-|-|
